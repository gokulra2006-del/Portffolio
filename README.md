# Gokul's Portfolio

A modern, responsive portfolio built with React, TypeScript, and Vite.

## Live Deployment

🚀 **View the live portfolio here:** [https://portffolio-35jacgw0t-gokulra2006-dels-projects.vercel.app](https://portffolio-35jacgw0t-gokulra2006-dels-projects.vercel.app)

## Tech Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS (or standard CSS modules)
- **Deployment:** Vercel

## Running Locally

To run this project on your local machine:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
